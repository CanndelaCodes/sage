# `sage setup`

Initialize `~/.sage/sage.json` and the agent workspace.

Related:

- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
sage setup
sage setup --workspace ~/.sage/workspace
```

To run the wizard via setup:

```bash
sage setup --wizard
```
